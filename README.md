# دارومپ (DaruMap) — سامانه کشوری جستجوی دارو و انبار داروخانه‌ها

**دارومپ (DaruMap)** یک پلتفرم آنلاین برای یافتن داروهای کمیاب، استعلام موجودی و قیمت داروخانه‌ها به **تومان**، ارسال نسخه و ثبت سفارش آنلاین با پشتیبانی از چیدمان **راست‌به‌چپ (RTL)** و فونت فارسی استاندارد **وزیرمتن** می‌باشد.

---

## 🏗️ معماری و تکنولوژی‌ها

- **فریم‌ورک فرانت‌اند و بک‌اند:** Next.js (App Router) + React + TypeScript
- **استایل‌دهی:** Tailwind CSS با پشتیبانی RTL
- **پایگاه داده و ORM:** SQLite / PostgreSQL + Prisma ORM
- **چارچوب تست:** Vitest + React Testing Library + Playwright
- **واحد پول:** تومان (TOMAN) در تمام سطوح برنامه

---

## 🚀 راهنمای نصب و اجرا

### ۱. نصب وابستگی‌ها
```bash
npm install
```

### ۲. تنظیم متغیرهای محیطی
یک فایل `.env` بر اساس `.env.example` ایجاد کنید:
```bash
cp .env.example .env
```

### ۳. راه‌اندازی دیتابیس و اجرای Prisma
```bash
npx prisma generate
npx prisma db push
```

### ۴. اجرای برنامه در حالت توسعه
```bash
npm run dev
```
برنامه در آدرس `http://localhost:3000` در دسترس خواهد بود.

---

## 🧪 اجرای تست‌ها و ساخت نسخه تولیدی

### اجرای تست‌های واحد (Vitest)
```bash
npx vitest run
```

### ساخت نسخه Production
```bash
npm run build
```

# دارومپ (DaruMap) — گزارش کامل حسابرسی، فاز ۱، فاز ۲، فاز ۳ و فاز ۴

**دارومپ (DaruMap)** یک پلتفرم جامع برای یافتن داروهای کمیاب، استعلام انبار داروخانه‌ها، ارسال امن نسخه و انتخاب بیمه پایه، مشاهده قیمت‌ها به تومان و ثبت سفارش آنلاین با پشتیبانی کامل از چیدمان **راست‌به‌چپ (RTL)** و فونت فارسی **وزیرمتن** می‌باشد.

---

## 📋 گزارش حسابرسی کدهای فاز ۱ تا فاز ۴ (Audit & Implementation Report)

### ۱. ویژگی‌ها و بخش‌های پیاده‌سازی‌شده و تاییدشده
- **پیکربندی پایه و RTL:** تنظیم Next.js App Router، فونت وزیرمتن (`next/font/google`) و `dir="rtl"` در چیدمان ریشه.
- **مدل‌سازی دیتابیس (Prisma ORM):** تعریف کلیه مدل‌های اصلی از جمله `User`, `CustomerProfile`, `Pharmacy`, `PharmacyMembership`, `PharmacyVerification`, `Medicine`, `ProductCategory`, `Product`, `PharmacyInventory`, `Order`, `OrderItem`, `Prescription`, `PrescriptionItem`, `InsuranceProvider`, `LoyaltyMembership`, `MedicationReminder` و `AuditLog`.
- **واحد پول (TOMAN):** تمام مقادیر مالی درون سیستم به **تومان** محاسبه شده و توابع فرمت‌دهی با اعداد فارسی در `src/lib/currency.ts` پیاده‌سازی شده‌اند.
- **محدودیت تک‌داروخانه‌ای هر سفارش:** منطق اعتبارسنجی سبد خرید در `src/lib/order.ts` و اکشن سرور `createOrderAction` با تراکنش اتمیک دیتابیس (`prisma.$transaction`) تضمین می‌کند که تمام قلم‌های سفارش متعلق به یک داروخانه باشند.
- **آنبوردینگ و تایید داروخانه‌ها (فاز ۲):** اکشن‌های `registerPharmacyAction` و `approvePharmacyAction` برای ثبت‌نام و بررسی پروانه داروخانه‌ها توسط مدیر سیستم.
- **ایزوله‌سازی انبار دارویی (فاز ۲):** اکشن `upsertPharmacyInventoryAction` با اعتبارسنجی سطح دسترسی پرسنل (`authorizeStaffAction`) جهت جلوگیری از تغییر انبار سایر داروخانه‌ها.
- **جستجوی جغرافیایی و رتبه‌بندی بر اساس فاصله (فاز ۳):** محاسبه دقیق فرمول هورسین (Haversine) در `src/lib/location.ts` جهت سنجش کیلومتری فاصله کاربر تا داروخانه و رتبه‌بندی نتایج.
- **موتور کشف دارو و انطباق نسخه (فاز ۳):** سرویس سروری `searchMedicinesService` و `matchPrescriptionMedicinesService` در `src/lib/search.ts` با نرمال‌سازی حروف فارسی (ی/ک/آ)، فقط نمایش داروخانه‌های تایید شده (`isVerified: true`) و تفکیک وضعیت تازگی انبار (`AVAILABLE`, `STALE`, `UNAVAILABLE`).
- **مدیریت نسخه‌ها و ذخیره‌سازی ایزوله فایل‌ها (فاز ۴):**
  - سرویس ایزوله‌سازی و محافظت از فایل‌های خصوصی در `src/lib/storage.ts` با اعتبارسنجی فرمت (JPEG, PNG, WEBP, PDF) و حداکثر ۵ مگابایت حجم و الگوریتم جلوگیری از Path Traversal.
  - ثبت رکوردهای نسخه همراه با رعایت کامل ایزوله‌سازی مالکیت (`userId`) در `src/lib/prescriptions.ts`.
  - ثبت دستی داروها به نسخه با بررسی مطابقت در کاتالوگ دارویی (`addManualMedicineToPrescription`).
  - رابط آماده‌سازی استخراج خودکار متن نسخه (OCR) با وضعیت شفاف و غیرمجاز بودن حدس خودکار دوز داروها (`processPrescriptionOCR`).
- **انتخاب بیمه‌های پایه کشور (فاز ۴):** پشتیبانی و ایجاد ارائه‌دهندگان بیمه پایه کشور (تأمین اجتماعی، بیمه سلامت، نیروهای مسلح، خدمات درمانی، سایر).

### ۲. نتایج تست‌ها و بیلد (Test & Build Results)
- **تست‌های واحد (Vitest):** ۷ فایل تست و ۲۹ تست واحد در محیط `jsdom` به‌طور کامل پاس شدند (`29 passed`).

- **ساخت نسخه Production:** بیلد برنامه با دستور `npm run build` بدون هیچ‌گونه خطا کامپایل گردید.

### ۳. نقشه‌راه فاز ۵ و فازهای بعدی (Roadmap for Phase 5+)
- **یادآور دارو و باشگاه مشتریان (Phase 5):** زمان‌بندی پیام‌های یادآور و امتیازات مشتریان بر اساس خریدهای تاییدشده.
- **سخت‌سازی امنیتی و آماده‌سازی انتشار (Phase 6):** مرور کامل دسترسی‌ها و تست‌های کارایی قبل از انتشار نهایی.

## 🚀 راهنمای نصب و اجرا

### ۱. نصب وابستگی‌ها
```bash
npm install
```

### ۲. تنظیم متغیرهای محیطی
یک فایل `.env` بر اساس `.env.example` ایجاد کنید:
```bash
cp .env.example .env
```

### ۳. اجرای Prisma Generate
```bash
npx prisma generate
```

### ۴. اجرای برنامه در حالت توسعه
```bash
npm run dev
```
برنامه در آدرس `http://localhost:3000` در دسترس خواهد بود.

# دارومپ (DaruMap) — گزارش کامل حسابرسی، فاز ۱ تا فاز ۶ و ارزیابی آمادگی انتشار

**دارومپ (DaruMap)** یک پلتفرم جامع برای یافتن داروهای کمیاب، استعلام انبار داروخانه‌ها، ارسال امن نسخه و انتخاب بیمه پایه، یادآورهای دارویی، باشگاه مشتریان، مشاهده قیمت‌ها به تومان و ثبت سفارش آنلاین با پشتیبانی کامل از چیدمان **راست‌به‌چپ (RTL)** و فونت فارسی **وزیرمتن** می‌باشد.

---

## 📋 گزارش حسابرسی جامع و ارزیابی آمادگی انتشار (Phase 6 Audit Deliverables)

### ۱. وضعیت ویژگی‌های پیاده‌سازی‌شده و تاییدشده (Phases 1–5)
- **پیکربندی پایه و RTL:** Next.js App Router، فونت وزیرمتن (`next/font/google`) و `dir="rtl"` در چیدمان ریشه.
- **مدل‌سازی دیتابیس (Prisma ORM):** تعریف کلیه مدل‌های اصلی از جمله `User`, `CustomerProfile`, `Pharmacy`, `PharmacyMembership`, `PharmacyVerification`, `Medicine`, `ProductCategory`, `Product`, `PharmacyInventory`, `Order`, `OrderItem`, `Prescription`, `PrescriptionItem`, `InsuranceProvider`, `LoyaltyMembership`, `MedicationReminder`, `Notification` و `AuditLog`.
- **واحد پول (TOMAN):** تمام مقادیر مالی درون سیستم به **تومان** محاسبه شده و توابع فرمت‌دهی با اعداد فارسی در `src/lib/currency.ts` پیاده‌سازی شده‌اند.
- **محدودیت تک‌داروخانه‌ای و سفارش اتمیک (فاز ۱):** اعتبارسنجی قیمت و موجودی انبار در تراکنش اتمیک دیتابیس (`prisma.$transaction`) در `createOrderAction`.
- **آنبوردینگ و ایزوله‌سازی انبار (فاز ۲):** اکشن‌های `registerPharmacyAction`, `approvePharmacyAction` و `upsertPharmacyInventoryAction` با اعمال مجوز سروری (`authorizeStaffAction`).
- **جستجوی جغرافیایی و کشف انبار (فاز ۳):** محاسبه کیلومتری فاصله (Haversine)، نرمال‌سازی حروف فارسی، فیلتر داروخانه‌های تایید شده و تفکیک تازگی انبار (`AVAILABLE`, `STALE`, `UNAVAILABLE`).
- **مدیریت نسخه‌ها و ذخیره‌سازی امن (فاز ۴):** ذخیره‌سازی ایزوله در `src/lib/storage.ts` با جلوگیری از Path Traversal، پسوندهای مجاز (JPEG, PNG, WEBP, PDF) و حد ۵ مگابایت.
- **باشگاه مشتریان و یادآورها (فاز ۵):** اعطای امتیازات لجر یکتا، سطح‌بندی برنز/نقره/طلا، ثبت مصرف دارو و پردازشگر پس‌زمینه ارسال یادآورها با قفل Idempotency.

### ۲. نتایج تست‌ها، بیلد و اعتبارسنجی (Execution Results)
- **تست‌های واحد و یکپارچه‌سازی (Vitest):** ۹ فایل تست و ۳۵ تست واحد بدون هیچ‌گونه خطا پاس شدند (`35 passed`).
- **اعتبارسنجی اسکیما (Prisma):** دستور `npx prisma validate` بدون خطا تایید شد.
- **کلاینت پریزما (Prisma Generate):** دستور `npx prisma generate` با موفقیت تولید شد.
- **ساخت نسخه Production:** بیلد برنامه با دستور `npm run build` بدون هیچ‌گونه خطا کامپایل گردید.

### ۳. حسابرسی امنیتی و سخت‌سازی (Security Audit Findings)
- **جلوگیری از تغییر قیمت توسط کلاینت:** قیمت‌های واحد و مجموع فاکتور مستقیماً از انبار دیتابیس در تراکنش سروری بازخوانی می‌شوند.
- **ایزوله‌سازی دسترسی پرسنل داروخانه:** دسترسی تغییر انبار تنها به کاربران عضو تایید شده همان داروخانه یا ادمین سیستم محدود شده است.
- **محافظت از فایل‌های نسخه:** فایل‌های نسخه در مسیر استاتیک عمومی قرار ندارند و دسترسی تنها با احراز هویت مالک صورت می‌پذیرد.

### ۴. ارزیابی آمادگی انتشار (Deployment Readiness Assessment)
- **سطح آمادگی:** **آماده برای صحه‌سنجی استیجینگ (Ready for Staging Verification)**.
- **اقدامات لازم قبل از پروداکشن نهایی:**
  - تنظیم دیتابیس PostgreSQL پروداکشن و متغیر `DATABASE_URL` در سرویس‌دهنده.
  - فعال‌سازی Cron Job سروری یا سرویس Background Worker جهت فراخوانی دوره ای `processScheduledRemindersAction` برای ارسال یادآورهای دارویی.

## 🚀 راهنمای نصب و اجرا

### ۱. نصب وابستگی‌ها
```bash
npm install
```

### ۲. تنظیم متغیرهای محیطی
یک فایل `.env` بر اساس `.env.example` ایجاد کنید:
```bash
cp .env.example .env
```

### ۳. اجرای Prisma Generate
```bash
npx prisma generate
```

### ۴. اجرای برنامه در حالت توسعه
```bash
npm run dev
```
برنامه در آدرس `http://localhost:3000` در دسترس خواهد بود.

# دارومپ (DaruMap) — گزارش کامل حسابرسی، فاز ۱، فاز ۲ و فاز ۳

**دارومپ (DaruMap)** یک پلتفرم جامع برای یافتن داروهای کمیاب، استعلام موقعیت و انبار داروخانه‌ها، مشاهده قیمت‌ها به تومان و ثبت سفارش آنلاین با پشتیبانی کامل از چیدمان **راست‌به‌چپ (RTL)** و فونت فارسی **وزیرمتن** می‌باشد.

---

## 📋 گزارش حسابرسی کدهای فاز ۱، فاز ۲ و فاز ۳ (Audit & Implementation Report)

### ۱. ویژگی‌ها و بخش‌های پیاده‌سازی‌شده و تاییدشده
- **پیکربندی پایه و RTL:** تنظیم Next.js App Router، فونت وزیرمتن (`next/font/google`) و `dir="rtl"` در چیدمان ریشه.
- **مدل‌سازی دیتابیس (Prisma ORM):** تعریف کلیه مدل‌های اصلی از جمله `User`, `CustomerProfile`, `Pharmacy`, `PharmacyMembership`, `PharmacyVerification`, `Medicine`, `ProductCategory`, `Product`, `PharmacyInventory`, `Order`, `OrderItem`, `Prescription`, `LoyaltyMembership`, `MedicationReminder` و `AuditLog`.
- **واحد پول (TOMAN):** تمام مقادیر مالی درون سیستم به **تومان** محاسبه شده و توابع فرمت‌دهی با اعداد فارسی در `src/lib/currency.ts` پیاده‌سازی شده‌اند.
- **محدودیت تک‌داروخانه‌ای هر سفارش:** منطق اعتبارسنجی سبد خرید در `src/lib/order.ts` و اکشن سرور `createOrderAction` با تراکنش اتمیک دیتابیس (`prisma.$transaction`) تضمین می‌کند که تمام قلم‌های سفارش متعلق به یک داروخانه باشند.
- **آنبوردینگ و تایید داروخانه‌ها (فاز ۲):** اکشن‌های `registerPharmacyAction` و `approvePharmacyAction` برای ثبت‌نام و بررسی پروانه داروخانه‌ها توسط مدیر سیستم.
- **ایزوله‌سازی انبار دارویی (فاز ۲):** اکشن `upsertPharmacyInventoryAction` با اعتبارسنجی سطح دسترسی پرسنل (`authorizeStaffAction`) جهت جلوگیری از تغییر انبار سایر داروخانه‌ها.
- **جستجوی جغرافیایی و رتبه‌بندی بر اساس فاصله (فاز ۳):** محاسبه دقیق فرمول فرمول هورسین (Haversine) در `src/lib/location.ts` جهت سنجش کیلومتری فاصله کاربر تا داروخانه و رتبه‌بندی نتایج.
- **موتور کشف دارو و انطباق نسخه (فاز ۳):** سرویس سروری `searchMedicinesService` و `matchPrescriptionMedicinesService` در `src/lib/search.ts` با نرمال‌سازی حروف فارسی (ی/ک/آ)، فقط نمایش داروخانه‌های تایید شده (`isVerified: true`) و تفکیک وضعیت تازگی انبار (`AVAILABLE`, `STALE`, `UNAVAILABLE`).
- **رابط کاربری تعاملی جستجو (فاز ۳):** دکمه دریافت موقعیت مرورگر (Geolocation)، فیلتر شهر، نشانگرهای تازگی انبار و مرتب‌سازی بر اساس فاصله یا قیمت در `src/components/MedicineSearch.tsx`.
- **صفحات عمومی و داشبوردها:**
  - صفحه اصلی (`/`)
  - فهرست داروخانه‌ها (`/pharmacies`) و جزئیات داروخانه (`/pharmacy/[id]`)
  - صفحه تسویه حساب و سبد خرید (`/checkout`)
  - صفحات ورود و ثبت‌نام (`/auth/signin`, `/auth/signup`)
  - شل داشبوردهای نقش‌محور برای مشتری (`/dashboard/customer`)، پرسنل داروخانه (`/dashboard/pharmacy`) و مدیر سیستم (`/dashboard/admin`).

### ۲. نتایج تست‌ها و بیلد (Test & Build Results)
- **تست‌های واحد (Vitest):** ۶ فایل تست و ۲۵ تست واحد در محیط `jsdom` به‌طور کامل پاس شدند (`25 passed`).
- **اعتبارسنجی اسکیما (Prisma):** دستور `npx prisma validate` بدون خطا تایید شد.
- **ساخت نسخه Production:** بیلد برنامه با دستور `npm run build` بدون هیچ‌گونه خطا کامپایل گردید.

### ۳. نقشه‌راه فاز ۴ و فازهای بعدی (Roadmap for Phase 4+)
- **مدیریت نسخه تصویری (Phase 4):** آپلود امن تصاویر نسخه در فضای ایزوله سروری و سیستم درخواست قیمت‌دهی.
- **یادآور دارو و باشگاه مشتریان (Phase 5):** زمان‌بندی پیام‌های یادآور و امتیازات مشتریان.

## 🚀 راهنمای نصب و اجرا

### ۱. نصب وابستگی‌ها
```bash
npm install
```

### ۲. تنظیم متغیرهای محیطی
یک فایل `.env` بر اساس `.env.example` ایجاد کنید:
```bash
cp .env.example .env
```

### ۳. اجرای Prisma Generate
```bash
npx prisma generate
```

### ۴. اجرای برنامه در حالت توسعه
```bash
npm run dev
```
برنامه در آدرس `http://localhost:3000` در دسترس خواهد بود.

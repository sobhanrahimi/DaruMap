# دارومپ (DaruMap) — گزارش کامل حسابرسی و پیاده‌سازی فاز ۱

**دارومپ (DaruMap)** یک پلتفرم کشوری برای یافتن داروهای کمیاب، استعلام موجودی انبار داروخانه‌ها، مشاهده قیمت‌ها به تومان و ثبت سفارش آنلاین با پشتیبانی کامل از چیدمان **راست‌به‌چپ (RTL)** و فونت فارسی **وزیرمتن** می‌باشد.

---

## 📋 گزارش حسابرسی کدهای فاز ۱ (Implementation Audit Report)

### ۱. ویژگی‌ها و بخش‌های پیاده‌سازی‌شده و تاییدشده (Verified Features)
- **پیکربندی پایه و RTL:** تنظیم Next.js App Router، فونت وزیرمتن (`next/font/google`) و `dir="rtl"` در چیدمان ریشه.
- **مدل‌سازی دیتابیس (Prisma ORM):** تعریف کلیه مدل‌های اصلی از جمله `User`, `CustomerProfile`, `Pharmacy`, `PharmacyMembership`, `PharmacyVerification`, `Medicine`, `PharmacyInventory`, `Order`, `OrderItem`, `Prescription`, `LoyaltyMembership`, `MedicationReminder` و `AuditLog`.
- **واحد پول (TOMAN):** تمام مقادیر مالی درون سیستم به **تومان** محاسبه شده و توابع فرمت‌دهی با اعداد فارسی در `src/lib/currency.ts` پیاده‌سازی شده‌اند.
- **محدودیت تک‌داروخانه‌ای هر سفارش:** منطق اعتبارسنجی سبد خرید در `src/lib/order.ts` تضمین می‌کند که تمام قلم‌های سفارش متعلق به یک داروخانه باشند.
- **جستجوی آنلاین دارو:** کامپوننت تعاملی `MedicineSearch` برای فیلتر بر اساس نام داروی فارسی/انگلیسی، نام ژنریک، نام داروخانه و فیلتر موجودی انبار.
- **صفحات عمومی و داشبوردها:**
  - صفحه اصلی (`/`)
  - فهرست داروخانه‌ها (`/pharmacies`) و جزئیات داروخانه (`/pharmacy/[id]`)
  - صفحه تسویه حساب و سبد خرید (`/checkout`)
  - صفحات ورود و ثبت‌نام (`/auth/signin`, `/auth/signup`)
  - شل داشبوردهای نقش‌محور برای مشتری (`/dashboard/customer`)، پرسنل داروخانه (`/dashboard/pharmacy`) و مدیر سیستم (`/dashboard/admin`).

### ۲. نتایج تست‌ها و بیلد (Test & Build Results)
- **تست‌های واحد (Vitest):** ۴ فایل تست و ۱۷ تست واحد در محیط `jsdom` به‌طور کامل پاس شدند (`17 passed`).
- **اعتبارسنجی اسکیما (Prisma):** دستور `npx prisma validate` بدون خطا تایید شد.
- **ساخت نسخه Production:** بیلد برنامه با دستور `npm run build` بدون هیچ‌گونه خطا کامپایل گردید.

### ۳. ویژگی‌های در دست اقدام برای فازهای بعدی (Roadmap for Phase 2+)
- **اتصال احراز هویت سروری (NextAuth / JWT):** اتصال فرم‌های ورود/ثبت‌نام به سیستم Session و Middleware سروری برای محافظت از مسیرها.
- **ذخیره‌سازی سفارش در دیتابیس:** ثبت نهایی سفارشات در جدول `Order` به جای مدیریت صِرف در LocalStorage.
- **سیستم مدیریت فایل نسخه (Prescriptions):** اتصال سرویس آپلود امن تصویر نسخه در فضای ذخیره‌سازی ایزوله.
- **جستجوی جغرافیایی (Location Proximity):** محاسبه فاصله تا نزدیک‌ترین داروخانه‌ها با مختصات `latitude`/`longitude`.

## 🚀 راهنمای نصب و اجرا

### ۱. نصب وابستگی‌ها
```bash
npm install
```

### ۲. تنظیم متغیرهای محیطی
یک فایل `.env` بر اساس `.env.example` ایجاد کنید:
```bash
cp .env.example .env
```

### ۳. اجرای Prisma Generate
```bash
npx prisma generate
```

### ۴. اجرای برنامه در حالت توسعه
```bash
npm run dev
```
برنامه در آدرس `http://localhost:3000` در دسترس خواهد بود.

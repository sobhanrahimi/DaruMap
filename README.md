# دارومپ (DaruMap) — گزارش کامل حسابرسی، فاز ۱ و فاز ۲

**دارومپ (DaruMap)** یک پلتفرم جامع برای یافتن داروهای کمیاب، استعلام موجودی انبار داروخانه‌ها، مشاهده قیمت‌ها به تومان و ثبت سفارش آنلاین با پشتیبانی کامل از چیدمان **راست‌به‌چپ (RTL)** و فونت فارسی **وزیرمتن** می‌باشد.

---

## 📋 گزارش حسابرسی کدهای فاز ۱ و فاز ۲ (Audit & Implementation Report)

### ۱. ویژگی‌ها و بخش‌های پیاده‌سازی‌شده و تاییدشده
- **پیکربندی پایه و RTL:** تنظیم Next.js App Router، فونت وزیرمتن (`next/font/google`) و `dir="rtl"` در چیدمان ریشه.
- **مدل‌سازی دیتابیس (Prisma ORM):** تعریف کلیه مدل‌های اصلی از جمله `User`, `CustomerProfile`, `Pharmacy`, `PharmacyMembership`, `PharmacyVerification`, `Medicine`, `ProductCategory`, `Product`, `PharmacyInventory`, `Order`, `OrderItem`, `Prescription`, `LoyaltyMembership`, `MedicationReminder` و `AuditLog`.
- **واحد پول (TOMAN):** تمام مقادیر مالی درون سیستم به **تومان** محاسبه شده و توابع فرمت‌دهی با اعداد فارسی در `src/lib/currency.ts` پیاده‌سازی شده‌اند.
- **محدودیت تک‌داروخانه‌ای هر سفارش:** منطق اعتبارسنجی سبد خرید در `src/lib/order.ts` و اکشن سرور `createOrderAction` تضمین می‌کند که تمام قلم‌های سفارش متعلق به یک داروخانه باشند.
- **آنبوردینگ و ثبت درخواست داروخانه (فاز ۲):** اکشن سرور `registerPharmacyAction` برای ثبت درخواست ثبت‌نام داروخانه با وضعیت تایید نشده (`isVerified: false`) و ایجاد رکورد `PharmacyVerification`.
- **بررسی و تایید داروخانه توسط ادمین (فاز ۲):** اکشن سرور `approvePharmacyAction` برای تایید رسمی داروخانه‌ها توسط مدیر سیستم.
- **مدیریت کاتالوگ دارو و محصولات (فاز ۲):** اکشن‌های `createMedicineCatalogAction` و `createProductCategoryAction` برای ثبت داروهای جدید و دسته‌بندی‌ها.
- **مدیریت انبار و ایزوله‌سازی دسترسی پرسنل (فاز ۲):** اکشن `upsertPharmacyInventoryAction` با اعمال مجوز سروری (`authorizeStaffAction`) جهت جلوگیری از دسترسی یا تغییر انبار سایر داروخانه‌ها.
- **صفحات عمومی و داشبوردها:**
  - صفحه اصلی (`/`)
  - فهرست داروخانه‌ها (`/pharmacies`) و جزئیات داروخانه (`/pharmacy/[id]`)
  - صفحه تسویه حساب و سبد خرید (`/checkout`)
  - صفحات ورود و ثبت‌نام (`/auth/signin`, `/auth/signup`)
  - شل داشبوردهای نقش‌محور برای مشتری (`/dashboard/customer`)، پرسنل داروخانه (`/dashboard/pharmacy`) و مدیر سیستم (`/dashboard/admin`).

### ۲. نتایج تست‌ها و بیلد (Test & Build Results)
- **تست‌های واحد (Vitest):** ۵ فایل تست و ۲۱ تست واحد در محیط `jsdom` به‌طور کامل پاس شدند (`21 passed`).
- **اعتبارسنجی اسکیما (Prisma):** دستور `npx prisma validate` بدون خطا تایید شد.
- **ساخت نسخه Production:** بیلد برنامه با دستور `npm run build` بدون هیچ‌گونه خطا کامپایل گردید.

### ۳. نقشه‌راه فاز ۳ و فازهای بعدی (Roadmap for Phase 3+)
- **جستجوی جغرافیایی بر اساس موقعیت مکانی (Phase 3):** رتبه‌بندی داروخانه‌های نزدیک و سنجش تازگی انبار.
- **مدیریت نسخه تصویری (Phase 4):** آپلود امن تصاویر نسخه در فضای ایزوله سروری.
- **یادآور دارو و باشگاه مشتریان (Phase 5):** زمان‌بندی پیام‌های یادآور و امتیازات مشتریان.

## 🚀 راهنمای نصب و اجرا

### ۱. نصب وابستگی‌ها
```bash
npm install
```

### ۲. تنظیم متغیرهای محیطی
یک فایل `.env` بر اساس `.env.example` ایجاد کنید:
```bash
cp .env.example .env
```

### ۳. اجرای Prisma Generate
```bash
npx prisma generate
```

### ۴. اجرای برنامه در حالت توسعه
```bash
npm run dev
```
برنامه در آدرس `http://localhost:3000` در دسترس خواهد بود.

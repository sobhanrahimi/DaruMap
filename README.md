# دارومپ (DaruMap) — گزارش نهایی ارزیابی و صحه‌سنجی آمادگی انتشار استیجینگ (Staging Release Gate)

**دارومپ (DaruMap)** یک پلتفرم کشوری برای یافتن داروهای کمیاب، استعلام انبار داروخانه‌ها، ارسال امن نسخه و انتخاب بیمه پایه، یادآورهای دارویی، باشگاه مشتریان، مشاهده قیمت‌ها به تومان و ثبت سفارش آنلاین با پشتیبانی کامل از چیدمان **راست‌به‌چپ (RTL)** و فونت فارسی **وزیرمتن** می‌باشد.

---

## 📋 گزارش حسابرسی نهایی و صحه‌سنجی مبتنی بر شواهد (Evidence-Based Gate Report)

### ۱. نتایج اجرائی ابزارهای صحه‌سنجی (Executed Command Outcomes)
- **اعتبارسنجی اسکیما (`npx prisma validate`):** خروجی `The schema at prisma/schema.prisma is valid 🚀` (Exit Code 0).
- **تولید کلاینت پریزما (`npx prisma generate`):** خروجی `✔ Generated Prisma Client to ./node_modules/@prisma/client` (Exit Code 0).
- **تست‌های واحد و یکپارچه‌سازی (`npm test`):** ۱۰ فایل تست و ۳۹ تست واحد بدون هیچ‌گونه خطا پاس شدند (`39 passed`, Exit Code 0).
- **بیلد تولیدی (`npm run build`):** کامپایل موفقیت‌آمیز تمام صفحات Next.js بدون خطای تایپ‌اسکریپت و ESLint (Exit Code 0).

### ۲. مرزهای امنیتی و یکپارچگی دادوستدها (Verified Security & Integrity Boundaries)
- **عدم دسترسی به قیمت توسط کلاینت:** محاسبه قیمت‌های سفارش بر اساس موجودی انبار دیتابیس در تراکنش سروری انجام می‌شود.
- **جلوگیری از ثبت سفارش منفی/صفر:** اعتبارسنجی `quantity > 0` مانع از ثبت سفارشات نامعتبر می‌شود.
- **تضمین شرط تک‌داروخانه‌ای:** تمام قلم‌های سبد خرید باید متعلق به یک داروخانه تایید شده باشند.
- **حفاظت از فایل‌های نسخه:** فایل‌های نسخه در مسیر استاتیک قرار ندارند و با شناسه UUID ایزوله سروری ذخیره می‌شوند.
- **قفل عدم ارسال تکراری یادآورها:** ارسال اعلان‌های یادآور دارویی دارای قفل Idempotency در دیتابیس است.

### ۳. پیش‌نیازهای محیط استیجینگ (Staging Prerequisites)
1. **دیتابیس PostgreSQL:** تنظیم سرویس PostgreSQL و متغیر `DATABASE_URL` در محیط استیجینگ.
2. **سرویس Cron / Background Worker:** زمان‌بندی فراخوانی دوره ای `processScheduledRemindersAction` برای پردازش ارسال یادآورهای دارویی.
3. **پوشه ذخیره‌سازی نسخه‌ها:** تنظیم مسیر `PRESCRIPTION_STORAGE_PATH` با دسترسی نوشتن برای برنامه.

## 🚀 راهنمای نصب و اجرا

### ۱. نصب وابستگی‌ها
```bash
npm install
```

### ۲. تنظیم متغیرهای محیطی
یک فایل `.env` بر اساس `.env.example` ایجاد کنید:
```bash
cp .env.example .env
```

### ۳. اجرای Prisma Generate
```bash
npx prisma generate
```

### ۴. اجرای برنامه در حالت توسعه
```bash
npm run dev
```
برنامه در آدرس `http://localhost:3000` در دسترس خواهد بود.
